GITHUB PAGES SETUP

1. Sign in to GitHub and create a new PUBLIC repository, for example: ar-model.
2. Upload index.html and the complete models folder from this package.
3. Open the repository's Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait a few minutes for GitHub to display the live HTTPS address.
7. Generate a QR code using that live address, not the direct GLTF file address.

The two Illustrator exports are self-contained. No BIN file or texture folder is required.

The page defaults to Asset 2. Visitors can switch between Asset 1 and Asset 2.

Important: test the published page on both iPhone and Android before printing the QR code.
